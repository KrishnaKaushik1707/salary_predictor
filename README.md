# PlacementIQ 🚀

AI Powered Placement Prediction & Resume Analysis System

PlacementIQ is a full-stack AI-driven web application that helps students analyze their resumes, calculate ATS scores, predict placement probability, estimate salary packages, and compare resumes with job descriptions using Machine Learning and NLP.

---

# ✨ Features

## 📄 AI Resume Analysis
- Upload PDF/DOC resumes
- Automatic resume text extraction
- AI-powered skill detection
- ATS Resume Score generation

## 🤖 Placement Prediction
- Predicts placement chances using ML model
- Calculates placement probability
- Estimates expected salary package (LPA)

## 🎯 Job Description Matching
- Paste company job description
- Detects matched skills
- Shows missing skills
- Calculates job match percentage

## 💡 AI Recommendations
- Personalized improvement suggestions
- Resume enhancement tips
- Skill improvement recommendations

## 📊 Analytics Dashboard
- Student analytics visualization
- Placement statistics
- Performance tracking

# ⚙️ Installation & Setup

## 1️⃣ Clone Repository

```bash
git clone https://github.com/KrishnaKaushik1707/salary_predictor.git
cd salary_predictor
```

---

# 🚀 Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

Frontend runs on:

```bash
http://localhost:5173
```

---

# 🚀 Backend Setup

```bash
cd backend
npm install
nodemon index.js
```

Backend runs on:

```bash
http://localhost:1234
```

---

# 🚀 Machine Learning Setup

## Create Virtual Environment

```bash
cd machineLearning

python -m venv venv
```

## Activate Virtual Environment

### Mac/Linux

```bash
source venv/bin/activate
```

### Windows

```bash
venv\Scripts\activate
```

---

## Install Requirements

```bash
pip install -r requirements.txt
```

---

## Run Flask Server

```bash
python app.py
```

Flask ML server runs on:

```bash
http://127.0.0.1:8000
```
